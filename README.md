
# Introduction-to-Computers

It contains a full journey through eight decades of machines that learned to think, from a timeline of the core technology behind each era. Comparing the Generations, speed, size and technology.

## Introduction to Computers
A computer is an electronic device that manipulates data. Every generation of computing is defined by a shift in core circuit technology:
* **Speed:** From thousands to trillions of operations per second.
* **Size:** From room-sized machines to microchips.
* **Intelligence:** From fixed instructions to adaptive systems.
